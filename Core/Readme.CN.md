# README

​	Core文件夹是整个PDF浏览器阅览程序的核心。所有的核心交互都在这里

```
.
├───CCPDFView_Loader	# PDF 加载器
├───CCPDF_Error_Helper	# PDF 错误帮助组件
├───CCPDF_Historical	# PDF日志服务历史帮助机制
│   ├───FileRecord		# 日志与外界存储交互
│   └───Historical		# 日志
├───CCPDF_Info			# PDF 信息组件
├───CCPDF_MainView		# PDF主显示组件
├───CCPDF_PDFPageNavigator	# PDF页码导航
├───CCPDF_PdfServer		# PDF服务组件
├───CCPDF_PdfView		# 重载的PDF浏览器
├───CCPDF_SinglePDF_Component	# MdiWindow层的单PDF交互组件
├───CCPDF_TextHelper	# PDF本地文本提取
├───CCPDF_Utils			# PDF 通用工具集
└───CCPDF_ZoomController # PDF放缩
```
