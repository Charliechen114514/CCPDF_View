# README

![image-20240715210652898](./assets/README_FirstPage.png)

CCPDFView_Beta是一个简洁轻量的PDF阅读器程序，目前尚处于测试阶段。

## 更新3

- 支持朗读PDF的可选编译，语音包来自您计算机的默认TTSs
- 支持MSVC的多线程编译，对于Makefile用户，您可以通过在项目设置中提供-j参数来设置线程cnt
- 更多整洁的代码clang-format
- 更新在Translation Widget中显示字符串，现在您可以不用手动去掉换行了

## 更新2

1. 尝试支持一些动画
2. 支持命令行启动此PDF应用程序：目前支持到添加pdf列表参数

## 更新1

Updates:
1. 增加了快捷键帮助（介绍一下快捷键）
2. 增加菜单栏隐藏和翻译栏隐藏的功能
3. 补全了一些操作的快捷键（具体参考快捷键帮助）

手动更新指南：
1. 将Documentations移动到到可执行文件目录下做替换即可
2. 将可执行文件替换原来的就可以，所有的数据都不会发生任何丢失！

## 功能简单浏览

目前支持的功能：

> 阅读：
>
> > 基本的pdf页码跳转，阅读导航
> >
> > 日志支持的PDF记忆功能，对于用户没有关闭的文档下次打开自动定位到上一次浏览所在位置
>
> PDF浏览放大：
>
> > 支持PDF放大和缩小
> >
> > 当PDF放的相对较大，鼠标可以右键进行拖拽移动
>
> PDF服务
>
> > 解析原生的PDF书签且双击支持跳转，以便快速浏览章节
> >
> > 非图像渲染支持原生的文本信息提取
> >
> > 支持PDF内部的检索与项目跳转
> >
> > 支持识别PDF内部链接并点击跳转
>
> PDF书库
>
> > 支持书库浏览，方便的在程序内部遨游一个文件夹下的所有PDF程序
> >
> > 支持在给定目录下检索PDF的Title
>
> 插件操作：
>
> > 支持使用Tesseract OCR插件，使用关联项目的TesseractWrapper.dll作为DLL插件的兼容支持
> >
> > 支持用户侧自由的翻译程序兼容，只需要用户提供翻译EXE文件且满足文件名称规范即可在程序内部使用翻译插件
> >
> > 翻译模块支持自动翻译了，当您上下浏览PDF的时候，软件将会依照页面变化自动触发对插件程序的调用！无论单双页
>
> Qt主题自由注册：
>
> > 支持使用所有带有QSS格式的Qt主题，用户只需指定主题的QSS文件，便可以加载主题并记忆保留，直到用户删除为止。
>
> 多页阅读模式：
>
> > 现在我们的PDF运行程序支持多页阅读，用户可以自由的使用鼠标浏览PDF
