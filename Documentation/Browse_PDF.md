# PDF阅览

## 阅览PDF

### 翻页

​	翻页支持如下的方式进行：

> 1. 使用快捷键：←键或者是A键上一页，→键或者是D键下一页
>
> 2. 使用工具栏中的
>
>    ![toNext](./Documentation/Browse_PDF/toNext.png)
>
>    键小图标翻到下一页，
>
>    ![toPrev](./Documentation/Browse_PDF/toPrev-1721349102002-3.png)
>
>    键翻到上一页
>
> 3. ![firstPage](./Documentation/Browse_PDF/firstPage.png)类比的，这是翻到第一页
>
> 4. ![lastPage](./Documentation/Browse_PDF/lastPage.png)这是翻到最后一页

### 放大缩小

​	放大缩小支持如下方式：

1. 点击工具栏中的

   ![zoomIn](./Documentation/Browse_PDF/zoomIn.png)![zoomOut](./Documentation/Browse_PDF/zoomOut.png)进行放大和缩小

2. 摁住Ctrl键 + 鼠标滚轮进行放大缩小（上滑放大，下滑缩小）

   > Catch Out: 值得注意的是，使用此类放大时，窗口优先捕捉的是上下滑动，故对于在中心处调整放大缩小，建议是点击工具栏进行。以免将视场中心移除目标外

### 拖拽

看官可以摁住鼠标右键，在放大的状态下拖拽阅览PDF
