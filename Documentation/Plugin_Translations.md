# 插件：翻译插件

翻译插件的配置较为复杂：您需要自行提供翻译插件，其格式满足：

> 1, 输出文件名称为：writing.plugin.output
>
> 2. 输出文件与翻译插件同级目录

软件将会实时监控翻译插件进程，待您的程序运行完毕时，软件就会读取上述提到的writing.plugin.output文件将内部的文件读取进入。

> 为什么没有显示结果或显示结果异常？
>
> > 您需要自己在命令行下运行您的插件程序，根据自己的插件反馈的结果对您的插件进行实时的调试，软件侧只是负责运行进程后，读取writing.plugin.output的文件结果，其余插件错误软件概不负责。

> 提示：对于封装了网页请求的翻译插件，请确保自己的网络可以访问到目标网站！
